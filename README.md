# Chess Clock

A clean, offline chess clock for Android, built with Flutter.

## Highlights

- Two-player tap-to-switch clock
- Configurable time controls
- Sound and visual feedback
- No account or network connection

## Build from source

```bash
flutter pub get
flutter run
```

Create a release APK with `flutter build apk --release`. The APK is written under `build/app/outputs/flutter-apk/`.

## Privacy

The app works offline and does not collect personal data.
